# Character Assets (borrowed placeholder)

These files came from the `@hmcs/assets` package by **notelm**, part of the
[Desktop Homunculus](https://github.com/not-elm/desktop-homunculus) project
(license: MIT AND CC-BY-4.0). We are not the authors of these files.

They're kept here as the **placeholder character** for Desktop Avatar until
Phase 5 of the roadmap (designing our own first avatar). Once we have our
own character, these should be removed and replaced.

- `vrm/Elmer.vrm` — the 3D character model
- `vrma/*.vrma` — animation clips (idle-maid, idle-sitting, grabbed)
- `se/*.mp3` — UI sound effects (open, close)
